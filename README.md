# microduck-s288

[English](README_EN.md) · 中文

用宇树 **S288** 舵机复刻 Pollen Robotics 的开源双足小鸭 [Microduck](https://github.com/pollen-robotics/microduck)。

> **状态（2026-09-22）：设计阶段，还没有实物。** 24 种打印件的 CAD 已出、能过全部几何检查，但整机没装过、策略没重训、
> 依赖实测的尺寸还没实测。现在放出来的只有这份说明和许可证；STL、源码、清单会在对应里程碑达成后陆续上传（见下"路线"）。
> **请不要按现在的内容去打印或采购。**

---

## 为什么要复刻

原版 Microduck 的仿真模型、训练代码和策略都开源了，但 **CAD 不公开**，用的 Dynamixel XL330 舵机在国内也不好买。
所以这个项目：

- **借**原版的仿真骨架与策略：14 条关节轴线一根不动，原版训练好的走路 / 起立 / 坐站策略作为能力基线；
- **重做**全部结构件：按宇树 S288（塑料齿、塑料壳、Ø10.5 分度圆、实测堵转 0.66 N·m）重新画可打印的结构，
  头壳、髋、偏航件、躯干壳等件在原版网格的毛坯上切削改造；
- **重训**：结构和电机都变了，策略要在按我们 CAD 生成的仿真模型上重新训练，不迁就原版限位。

## 现在有什么、到哪一步了

- **CAD**：24 种打印件，全部用 Python（trimesh + manifold）参数化生成，改一个尺寸整鸭重出。
- **检查体系（Gate）**：8 层自动检查——网格合法性、可打印性、特征是否真的切出来了、零位干涉、装配路径与起子可达、
  螺丝咬入与坐面、全行程与真实姿态碰撞、质量与扭矩。每轮改件后全量跑一遍，红绿逐条留证据，不许"看着没问题"。
  当前一轮：5601 个原版策略真实姿态里，本轮刚把最后一处走路时会碰的头壳让位切掉，正在验证。
- **仿真**：能按我们的 CAD 重新生成 MuJoCo 模型；重训流程搭好，尚未开跑。
- **实物**：舵机已到手，实机通信、归零和吊重扭矩测试做过；主控、摄像头、IMU 已下单未到；**整机未装**。
